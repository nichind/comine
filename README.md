# comine <img src="static\icon.png" align="right" height="90" alt="Comine logo (icon)" />

comine is a cross-platform media, file, torrent, gallery, & more downloader/archiver. Available on Windows, Linux, MacOS and Android.
Made with Tauri, Svelte and Rust.

> comine still in early development, expect bugs and missing features. Please report any issues you find on the [issues page](https://github.com/nichind/comine/issues). Pull requests are not accepted until the codebase is stabilized, request features on the issues page.

## Thanks

To developers of the open source projects/libraries that made comine possible
- [yt-dlp](https://github.com/yt-dlp/yt-dlp) - Main downloader tool of the app.
- [youtubedl-android](https://github.com/yausername/youtubedl-android) - For making the Android version possible.
- [aria2](https://github.com/aria2/aria2) - Insane downloading speeds and torrent support.
- [ffmpeg](https://ffmpeg.org/) - Video and audio processing.
- Hayase - Desktop sidebar & settings UI inspiration
- [gallery-dl](https://github.com/mikf/gallery-dl) - Tool for downloading from imageboards, archivers, etc.
- [Seal](https://github.com/JunkFood02/Seal) - Resolve & misc UI inspiration.
